# PharmEasy

PharmEasy is a lightweight web-based pharmacy management application designed to simplify everyday pharmacy operations. It includes modules for billing, inventory tracking, medication management, and employee attendance.

## Features

- **Inventory Management**: View, add, and update medication stock.
- **Billing System**: Generate and manage bills for customer purchases.
- **Medication Tracking**: Maintain records of medication changes.
- **Attendance**: Track staff attendance through a simple interface.


## Technologies Used

- HTML/CSS for frontend interface
- Plain text and CSV files for lightweight data storage

## How to Use

1. Open the `home.html` file in your web browser.
2. Navigate between billing, inventory, and attendance pages.
3. Data is stored locally in `.txt` and `.csv` files.

## Note

This is a static web project meant for demonstration or local use. No backend or database integration is included.
